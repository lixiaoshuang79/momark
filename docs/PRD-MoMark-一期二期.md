# 墨记 MoMark 产品需求文档：一期与二期

版本：1.0  
日期：2026-09-05  
状态：交付开发

## 1. 产品概述

墨记 MoMark 是面向 macOS 的原生 Markdown 编辑器：一期完整覆盖 MarkText 的核心编辑能力，二期完成定稿原型中的窗口结构、标签、多栏、浏览器面板和动效交互。阶段三暂不纳入本需求。

### 1.1 产品目标

- 用户可以新建、打开、编辑、保存和导出 Markdown 文档。
- 用户可以在多个文档之间切换、重排、关闭，并保持每个文档的独立内容和保存状态。
- 用户可以展开大纲、文件列表和右侧浏览器面板，形成文档与网页并排工作区。
- 所有关键页面状态、位置关系、文案和交互行为与原型一致。

### 1.2 不在本期范围

- 源码模式。
- 打字机模式。
- 阶段三尚未确定的能力。
- 原型中已删除的菜单演示条、图片占位块和标签栏新建按钮。

## 2. 一期：MarkText 核心编辑能力

### 2.1 文档生命周期

- 新建文档：通过系统菜单创建空文档，光标直接定位第一行，显示从这里开始写作…提示。
- 打开文档：支持 Finder、系统打开命令和应用内打开；支持一次选择多个 Markdown 或纯文本文件，每个文件独立进入标签。
- 打开文件夹：递归扫描文件夹中的 Markdown 文件，批量建立或复用标签。
- 保存：保存前展开所有折叠附件，保证写入的 Markdown 源码完整且无附件占位字符。
- 另存为：选择新路径后更新当前文档路径、标签名称和面包屑路径。
- 关闭：关闭当前标签；若有未保存改动，必须先选择取消、不保存或保存。关闭最后一个标签后保留空文档状态。
- 退出：任一标签存在未保存改动时，阻止直接退出并进入未保存处理流程。

### 2.2 Markdown 编辑与渲染

必须支持所见即所得编辑，并保持 Markdown 源码可逆转换：

- 标题 H1-H6。
- 粗体、斜体、删除线。
- 无序列表、有序列表、任务列表；回车自动延续列表，空列表项回车退出列表。
- 引用、分隔线、链接。
- 围栏代码块及语言标识。
- 表格：插入、展开、折叠、单元格编辑、增删行列、对齐设置，往返转换不丢失内容。
- 数学公式、Mermaid、iframe、图片、脚注、前置元数据、emoji shortcode。
- 图片粘贴或拖入：复制到文档目录下的 `assets/`，插入相对路径 Markdown。
- 代码块语言选择：自动识别、Swift、JavaScript、Python、Markdown、CSS；选择后更新语言标识并提示结果。

### 2.3 编辑操作

- `⌘B` 粗体，`⌘I` 斜体，`⌘⇧X` 删除线。
- `⌘K` 插入链接；有选区时包裹选中文本，无选区时插入链接模板。
- `⌘⇧8` 无序列表，`⌘⇧7` 有序列表。
- `⌘1` 至 `⌘6` 设置标题级别；重复同级快捷键移除标题。
- `⌘⇧>` 引用，`⌘⌥C` 围栏代码块。
- `⌘+`、`⌘-` 调整编辑器缩放，范围 50% 至 200%；`⌘0` 恢复默认。
- `⌘F` 查找，`⌥⌘F` 替换；支持大小写、全词匹配、查找下一个、替换当前、全部替换。
- 系统拼写检查可在偏好设置中开关。

### 2.4 自动保存与状态

- 已有路径文档默认在编辑后 5 秒自动保存；延迟可配置为 3 秒、5 秒或 10 秒。
- 未命名文档不自动弹出保存对话框。
- 文档修改后，当前标签文件名后显示 7px 墨蓝状态点；底部状态栏显示未保存的更改。
- 保存成功后移除状态点，状态栏显示已保存。
- 状态栏左侧点击后循环显示字数、段落、字符；默认显示字数，并采用千分位格式，例如字数 1,245。

### 2.5 导出与打印

- 支持导出 HTML、PDF、docx。
- 支持打印。
- HTML 导出不依赖 pandoc。
- PDF/docx 在缺少 pandoc 时，显示明确错误原因和处理入口。
- 导出过程中显示进度和取消入口，完成后显示成功或失败反馈。

## 3. 二期：原型窗口与协作式工作区

### 3.1 窗口总结构

窗口从上到下由标题栏、可选标签栏、面包屑行、三栏主体和底部状态栏组成。所有区域必须连续衔接，不得出现系统灰带或空白占位区域。

- 画布：`#FCFCFB`。
- 面板底：`#F9F9F7`；侧栏底：`#FAFAF9`；卡片底：`#FFFFFF`。
- 主文字：`#242422`；次级文字：`#65645F`；三级文字：`#898781`。
- 强调色：`#3D5A80`；深色主题强调色：`#7FA6CC`。
- 正文/UI 使用 Anthropic 字体；serif 标题使用 AnthropicSerif；代码使用系统等宽字体。
- CSS 原型尺寸换算为 macOS 界面尺寸时统一使用 `pt = px × 0.75`，不得局部混用。

### 3.2 标题栏与单文档状态

- 使用 macOS 原生红、黄、绿窗口按钮。
- 单文档状态不渲染标签栏。
- 单文档状态在标题区域居中显示墨蓝状态点和完整路径，例如 `~/Documents/momark › 产品需求文档.md`。
- 面包屑行不得重复显示路径、文件名或状态点；只保留右侧栏开关。
- 多文档或分栏状态的标题区域不显示重复窗口标题，文件名由标签或对应面包屑承载。

### 3.3 标签栏

- 多文档或分栏状态显示标签栏，单文档状态物理移除标签栏行。
- 标签只显示文件名，宽度随文件名自适应，最大宽度 420px，文件名不得省略截断。
- 活动标签使用深色文字和底部 2px 墨蓝滑轨；非活动标签使用次级文字。
- 未保存圆点位于文件名之后。
- 标签 hover 显示关闭按钮；仅剩一个标签时不显示关闭按钮。
- 标签栏不显示新建 `+` 按钮，新建和打开统一走系统菜单。
- 点击标签：滑轨真实横向移动并带轻微回弹；旧文档内容向切换反方向移出，新内容按行分层滑入。动效必须可中断，并遵循系统减少动态效果设置。
- 标签关闭后活动标签落到相邻标签；全部关闭后进入空文档状态。
- 标签可在栏内拖动重排，拖拽中显示半透明预览，释放后固化顺序并提示标签顺序已更新。

### 3.4 拖拽分屏

- 拖动任意标签时，无需预先打开右侧栏，窗口右侧出现半透明阴影投放区和拖动到此，分屏展开提示。
- 拖入投放区后，该文档从左侧标签集合移除，作为右侧独立窗格打开。
- 同一文档不得同时出现在左侧标签集合和右侧窗格。
- 分屏中央显示可拖动分隔线；左右窗格第一行内容顶部必须对齐。
- 分屏文档标题支持再次拖动回标签栏；回收后恢复为标准文件名标签，并收起右侧栏。
- 分隔线拖动范围：右栏最小 240px，最大为窗口宽度的 60%；拖至窗口宽度 90% 位置时自动关闭分屏。

### 3.5 左侧栏

- 左侧栏展开宽度为 288px，底色为 `#FAFAF9`，右侧使用 0.5px 发丝线。
- 顶部提供大纲、文件两个 tab；选中态为中性色胶囊，不使用墨蓝填充。
- 大纲 tab：展示 H1-H6 标题树，支持缩进、当前标题高亮和点击跳转；光标移动时同步高亮，不抢编辑区焦点。
- 文件 tab：展示当前文档所在目录的 Markdown 文件，显示文件图标、文件名和当前标记；点击文件打开或切换对应标签。
- 侧栏收起后宽度为 0，不允许保留空白占位。

### 3.6 右侧浏览器面板

- 右侧栏默认收起，展开宽度按原型为 288px；面板左侧使用 0.5px 发丝线。
- 标签栏右侧开关点击后向左滚动并变为圆形 X；再次点击恢复常态并收起面板，开合动效约 200 至 420ms。
- 网址/文档选择器紧跟右侧栏开关，不单独占用重复头部行；展开时由小矩形生长为大矩形并回弹，两个 tab 从右向左错峰滑入。
- 网址模式底部固定后退、前进、刷新和地址栏；地址栏为不透明白底，不自动聚焦。
- 鼠标移入地址栏时，右侧出现在默认浏览器中打开箭头；点击后调用系统默认浏览器打开当前 URL。
- 单网页状态：网页内容区右上角显示 34×34 圆角正方形 `+`；点击后地址栏横向生长，鼠标移出组件后自动收起。
- 多网页状态：右缘显示垂直 Dock，网址项和新增项统一 34×34 圆角正方形，距右侧保留 8px 空隙；hover 显示完整 URL 气泡，当前网页使用墨蓝边框。
- 文档模式底部只显示打开文件…入口，不显示网址导航条；选择本地 Markdown 后在右侧渲染预览。
- 网络加载中显示墨蓝进度线和加载状态；加载失败显示原因与重试按钮。
- 网页登录态、滚动位置和前进后退历史需要持续保留；本地文档预览必须清洗脚本、内联事件属性和不安全 iframe 来源。

### 3.7 编辑区视觉

- 内容列宽 720px，居中显示；正文区域使用近白暖灰画布。
- 正文使用 Anthropic 字体，标准字号 15px、行高 1.58。
- H1 使用 AnthropicSerif、30px、字重 500；H2 使用 sans、17px、字重 680；H3 使用 sans、16px、字重 670。
- 列表、引用、代码块、表格、链接、脚注和任务列表遵循设计系统中的颜色、间距、边线和圆角。
- 空文档不显示卡片或插画，仅保留第一行光标和从这里开始写作…提示。
- 编辑区聚焦时显示墨蓝焦点环，失焦时移除。

### 3.8 状态栏

- 高度 32px，上方使用发丝线。
- 左侧固定显示字数统计按钮，点击循环字数、段落、字符。
- 右侧固定显示已保存或未保存的更改；未保存状态同时显示墨蓝圆点。
- 状态栏不得显示光标行列、模式胶囊或重复路径。

## 4. 页面状态与交互流程

### 4.1 核心编辑流程

1. 启动应用进入空文档；光标定位第一行。
2. 用户输入 Markdown，编辑区即时渲染，字数与保存状态同步更新。
3. 用户通过菜单打开一个或多个文件；每个文件建立或复用独立标签。
4. 用户点击标签切换文档；内容、面包屑、大纲和保存状态随活动标签同步。
5. 用户拖动标签到右侧投放区进入分屏；右侧文档可再次拖回标签栏。
6. 用户关闭标签或退出应用；有未保存改动时必须完成保存决策。

### 4.2 网址工作流

1. 用户展开右侧栏，默认进入网址模式。
2. 用户点击悬浮 `+` 展开地址栏，输入关键词或 URL 后回车。
3. 关键词进入搜索流程，URL 自动补充 `https://`；加载期间显示进度，失败提供重试。
4. 用户 hover 地址栏，点击外开箭头后由默认浏览器打开当前页面。
5. 用户新增第二个网页后进入右缘 Dock 多网页状态，点击 Dock 项切换前台页面。

### 4.3 文档分屏工作流

1. 用户拖动文档标签进入右侧投放区。
2. 左侧标签栏移除该文档，右侧加载文档预览。
3. 左右两侧路径和状态点在同一面包屑层级左右对齐。
4. 用户拖动中央分隔线调整比例。
5. 用户拖动右侧文档标题回标签栏，右栏收起，文档恢复为活动标签。

## 5. 其他页面

### 5.1 命令面板

- 通过 `⌘⇧P` 打开居中浮层，宽 540pt，最大高 480pt。
- 命令按墨记、文件、编辑、视图、格式分组。
- 输入关键词实时过滤，命中词使用墨蓝字色加粗。
- 上下键移动选中项，回车执行；执行后关闭面板并显示 toast。
- 无结果时显示原因和修改关键词的提示。

### 5.2 偏好设置

- 窗口尺寸约 700×540pt。
- 提供通用、编辑器、Markdown、主题、拼写、图片 6 个 tab。
- 自动保存、自动保存延迟、主题、拼写检查等配置即时生效。
- 主题切换覆盖画布、面板、文字、边线和强调色。

### 5.3 关于、欢迎、导出与打印

- 关于窗口显示冻结的 MoMark Logo 和版本信息。
- 首次启动欢迎页显示无最近文件状态和新建文档入口。
- 导出和打印使用系统 sheet；导出失败需显示可执行的处理说明。

## 6. 视觉与交互验收标准

- 原型默认单文档、多文档、左栏展开、右栏网址、右栏文档五个场景均可稳定进入。
- 单文档不出现标签栏；多文档不出现新建 `+`；路径和文件名不重复。
- 右栏收起时不占宽；展开后网址/文档选择器位于右侧栏开关旁。
- 相同文档不得重复出现在左右两侧；分屏文档可拖回标签栏。
- 状态栏左字数、右保存状态，格式和位置符合原型。
- 画布、侧栏、卡片、文字和墨蓝强调色不得使用未定案的紫色、陶土色、羊皮纸色或系统灰替代。
- 关键动效必须使用真实位移、横向生长、回弹和分层滑入；不得只做原地透明度闪烁。
- 所有按钮、输入框和可拖拽区域具备清晰的悬停、按下、禁用和焦点反馈。
- 用户可通过原型顶部的聚合/全状态平铺模式逐项标注；开发验收需覆盖原型定义的全部状态。
