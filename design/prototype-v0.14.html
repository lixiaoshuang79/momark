墨记 MoMark 产品需求文档

MoMark（墨记）是一款原生 macOS 的 所见即所得 Markdown 编辑器，对标 MarkText。界面以「Claude Code 实机基准」绘制：近白暖灰画布 + 墨蓝 accent 点缀，链接示例：参见设计系统 §1 色彩令牌。

功能范围

输入 # 加空格后标题即时渲染，语法标记淡化显示；支持行内代码 let x = 1、任务列表与表格折叠。

  • 单窗所见即所得：语法输入即渲染，无需切换预览
  • 多标签页：每文件一个 tab，拖拽重排，Ctrl+Tab 循环
  • 中文字数统计：中文按字计，选中区独立统计
  1. 打开文档
  2. 编辑内容
  3. 导出 PDF 或 docx

设计原则

应用框架层采用 Claude Code 实机基准：Typora 式无缝极简 chrome；表格按 Claude Code 渲染（灰格无外框四角收圆）；图片工作流 = 直接粘贴/拖入即落盘渲染。

页面 P1 · 主编辑器窗口 ／ P2 · 右侧栏（状态矩阵见 PAGES.md）

编辑场景可 URL 直达：?page=editor&state=single｜multi｜split-doc｜split-url1｜split-urlN。single = 单文档打开：不渲染标签栏行，状态点与完整路径在标题行成组居中，下方不重复文件名；multi/split-* 渲染标签栏。活动标签使用独立墨蓝滑轨，正文切换为旧内容滑出、新内容分层滑入。右栏开关与「网址/文档」选择器使用生长回弹和错峰滑入；网址模式底部 = 后退/前进/刷新/地址栏，文档模式底部 = 打开文件。

场景直达 文档 模式（系统菜单） 网址侧栏（F5） 代码块（F2） 右侧栏 P2 六态 侧栏 标签栏 分栏（拖标签） 内容 外观 焦点 反馈

场景直达：上方 1.22–1.26 每个场景都可 URL 直达。1.22 单文档打开：无标签栏行，状态点与完整路径在标题行成组居中，下方不重复文件名。全状态标注：顶部切换「全状态平铺」，可在同一长页面连续查看全部 65 个可操作状态。
